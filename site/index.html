Free and open source

Free tools for DJs.

SetEngine is a Mac app that downloads music from YouTube, Spotify, SoundCloud, Deezer and Tidal links, works out the tracklist of a recorded DJ set, detects BPM and key, and helps you build setlists that mix in key. It costs nothing, there is no account, and all of the code is on GitHub.

Download for macOS View on GitHub

macOS only for now. Needs macOS 12 or later. Works on Apple Silicon and Intel.

Features

What it does

Two main tools, plus three smaller ones for your library.

CH 01 Download

Download
from a link

Paste a link from YouTube, YouTube Music, Spotify, SoundCloud, Deezer or Tidal. SetEngine works out whether it's a single track, a playlist or an album and adds it to the queue. You don't sign in to anything.

Output
MP3 up to 320 kbps, tagged, with cover art
Queue
Five downloads at once
Spotify
Needs spotdl installed, which is optional
Deezer, Tidal
Matched to the same recording on YouTube or SoundCloud; skipped if it can't be verified

CH 02 Set Extraction Beta

Get the tracklist
of a DJ set

Paste a link to a recorded DJ set on YouTube. If the uploader or someone in the comments posted a tracklist that covers the whole set, SetEngine uses that. It identifies the rest by directly analyzing the audio. You can then download single tracks or the whole set.

Cost
Free, with no account or API key
Privacy
The audio is fingerprinted on your Mac and is never uploaded
Limits
Unreleased tracks and bootlegs often can't be identified. The tracklist shows where the gaps are

ALSO INCLUDED

Also in the app

Three tools for the music you already have on disk.

Set Maker

Analyzes a folder for BPM and key, lets you rate tracks, and orders them into a setlist where each transition is in key. It imports and exports .m3u playlists.

Match Maker

Pick a track and it lists the ones in your library that mix with it, by key and BPM. Click a key on the wheel to see which keys go together.

Crate Sorter

Plays each track in a folder and copies it into the folders you choose when you press a number key. Your original files are not moved.

OPEN SOURCE

Free and
open source

SetEngine is free to download and free to use. There is no paid version and no account to create.

All of the source code is on GitHub under the MIT license. You can read it, change it and build it yourself. Bug reports and pull requests are welcome.

INSTALL

How to install it

  1. 01

    Download the disk image

    It is one 265 MB file that works on both Apple Silicon and Intel Macs.

  2. 02

    Drag it to Applications

    There is nothing else to install. yt-dlp and ffmpeg come inside the app, and it keeps yt-dlp up to date.

  3. 03

    Allow it the first time

    SetEngine isn't signed with a paid Apple developer certificate, so macOS blocks the first launch. Open System Settings, go to Privacy & Security and click Open Anyway. You only do this once.
